# @yokla/report

The reports of [yokla](https://www.npmjs.com/package/yokla): a terminal
summary, JUnit XML for CI, and an offline HTML report that shows each answer
next to its findings.

It depends only on `@yokla/core`. Most people run `yokla report` instead. The
guide in the yokla repository (`docs/guide/`) documents it.
