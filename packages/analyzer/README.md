# @yokla/analyzer

The analyzer of [yokla](https://www.npmjs.com/package/yokla): it reads a
target's repository and data, probes the live target, and proposes a profile
for a person to review, each entry with where it came from.

It depends on `@yokla/core` and `@yokla/runtime`. Most people run `yokla
analyze` instead. The guide in the yokla repository (`docs/guide/`)
documents it.
