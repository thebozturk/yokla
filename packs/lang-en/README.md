# @yokla/pack-lang-en

The English language pack of [yokla](https://www.npmjs.com/package/yokla). It
reads money, durations, number words and refusal wording in English, and
words yokla's attacks in English.

It depends only on `@yokla/core`. The `yokla` command uses it for a profile
that lists `en`.
