# @yokla/pack-lang-tr

The Turkish language pack of [yokla](https://www.npmjs.com/package/yokla). It
reads money, durations, number words and refusal wording in Turkish, so the
checks judge Turkish answers as they judge English ones, and words yokla's
attacks in Turkish, natively.

It depends only on `@yokla/core`. The `yokla` command uses it for a profile
that lists `tr`.
